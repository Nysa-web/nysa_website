NYSA COUTURE — WEBSITE
========================
Open index.html in a browser.

CONTACT PLACEHOLDERS
Replace the phone, WhatsApp, email, Instagram and Facebook text in index.html and contact.html.

PRODUCT IMAGES
Place your real product images in assets/products/ using the names:
product-01.jpg ... product-08.jpg
The current cards use styled placeholders until real images are added.

The website includes Home, Shop, Product, Cart, Checkout, Wishlist and Contact pages.
Cart data is stored in the browser localStorage.
